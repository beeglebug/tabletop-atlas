# V1 scope

Tabletop Atlas is a portfolio project demonstrating Next.js through a useful local field guide. The agreed journey is town/device-location search → synchronised map and accessible list → sourced venue profiles. The visual direction is a warm modern field guide with restrained journal accents.

## Included

- The Board Room in Bridgnorth and two contrasting real local retailers.
- Venue classification separate from shopping/play capabilities.
- Regional place search, positive-only offering filters, shareable URL state and browser history.
- Practical details, explicit unknown/conflicting facts, claim-level sources and distinct evidence dates.
- Mobile/desktop layouts, keyboard navigation and useful location/map/empty/404 recovery.
- Pre-rendered Next.js public content on Cloudflare through OpenNext, with a documented editorial rebuild/deploy workflow.
- Focused tests, measured deployed performance/accessibility, and a concise portfolio case study.

## Completion

The feature implementation is present. V1 is finished once the current edition is published, public checks pass, content limitations are explicit and hosting constraints are assessed. See the single [release checklist](docs/RELEASE.md) for outstanding work and evidence, the [README](README.md) for operation and the [case study](docs/CASE-STUDY.md) for portfolio context.

## Deferred

Accounts, working community submissions/confirmations, moderation, reviews, events, saved places, live stock, national/address search, automated venue acquisition and database persistence. Better photography, precise entrance pins and first-hand enthusiast observations can improve the editorial collection without introducing those features.
